# Magic Survive — 9월 3일 이후 팀 일정

## 일정 기준

- 프로젝트 시작: 2026년 8월 26일
- 오늘: 2026년 9월 3일, Day 9
- Day 30 제출일: 2026년 9월 24일
- 기능 완료 시각: 9월 17일 18:00
- 기능 동결: 9월 18일~24일. 신규 기능 금지, P0 결함·성능·밸런스만 수정
- 작업 카드 하나는 0.5~1인일이다. 한 사람의 하루 필수량 합계는 1인일을 넘기지 않는다. 0.5일 카드 두 개는 같은 날 가능하다.
- 9월 5~6일과 12~13일은 밀린 카드 회수용 주말 버퍼다. 새 필수 기능을 넣지 않는다.

필수 구현은 평일에만 배치했다. 주말 작업이 가능하면 9월 5~6일과 12~13일을 지연 회수에 쓰고, 불가능하면 회수 버퍼가 0이 된다. 첫 P0 지연이 생기는 즉시 P1을 동결하고 새 일정보다 미완 P0를 먼저 옮긴다.

## 9월 3일 기준 현실 확인

- 유신 기준 작업 `bfad21d`에는 10분 기획·계약 문서가 없다. 이 일정 배포 커밋을 새로 병합해야 한다.
- 승범의 고유 작업 `2ec3cfb`에는 진행 중 Damage UI 풀이 있다. 이후 기존 `Seondong` 병합 이력과 관계없이 이 일정 배포 커밋을 다시 병합해야 한다.
- 범위·융합 공격 실행, 실제 표식 효과, 엘리트·보스 요청 구독과 보스 처치 보고는 아직 없다.
- 일반 적 슬롯 4개 중 2개만 연결되어 있고 Basic·Fast 수치도 최종 기획과 다르다.
- 저장소에는 실제 게임용 VFX·SFX·SPUM 원본 에셋과 한국어 TMP 폰트가 없다.
- 태환의 9월 1일 육안 확인 뒤 9월 2~3일 통합 SHA에 대한 정확한 `6000.3.17f1` 검증은 없다.

따라서 첫 작업은 전원 문서 동기화와 수신 확인이다. 큰 최종 체크리스트를 통째로 맡기지 않는다.

현재 `ProjectileSpec`에는 원소·마법 ID·연쇄 수가 없어 기존 “새 공개 API 없음” 전제로는 조준 공격의 표식·연쇄를 완성할 수 없다. 이 일정은 SD02에서 기존 발사 데이터에 좁은 하위 호환 payload 확장 하나를 승인하는 것을 전제로 한다. 새 전투 시스템을 만드는 것이 아니며, 선동이 승인하지 않으면 YS07을 시작하지 않고 Gate에서 다시 범위를 정한다.

## Gate와 자동 컷

### Gate 1 — 9월 8일

필수: 전원 최신 문서 포함 SHA 사용, baseline PASS, YS03 표식 저장·초기화와 SB03 시작 원소 UI가 통합 SHA에서 동작.

실패하면 주말 버퍼를 미완 P0에 쓰고 P1 대기열을 동결한다.

### Gate 2 — 9월 12일

필수: 조준 마법 5개, 다섯 표식 효과, 융합 판정 기반, 공개 노드 기능 UI와 결과 화면이 통합 SHA에서 동작.

실패하면 9월 13일 버퍼를 미완 P0에 쓴다. YS06·YS08·SB11·SB12를 포함한 P1과 완성 VFX를 전부 보류하고 기존 회색 검증 UI를 삭제하지 않는다.

### Soft lock — 9월 16일

필수: 보스 생성·사망 보고·두 공격과 2단계 전환이 동작.

2단계가 불안정하면 새 원형 파동을 빼고 1단계의 안정된 두 공격을 20% 빠르게 반복한다.

### Feature Complete — 9월 17일 18:00

- P0가 아니거나 끝까지 연결되지 않은 기능은 비활성화한다.
- 실제 전투 효과가 없는 범위·숙련·융합 등 모든 P1 가지는 트리에서 숨긴다.
- 9월 18일 이후 미완 기능을 완성하려 하지 않는다.
- `main`은 9월 24일 최종 QA 승인 전까지 건드리지 않는다.

## P1·P2 당겨오기 대기열

필수 카드를 일찍 끝내고 다음 Gate가 PASS일 때만 위에서 하나씩 가져간다.

1. 유신: 범위 마법 5종 → 고유 원소 숙련 5종 → 나머지 융합 4종 → Tank → Ranged → 돌진 엘리트
2. 승범: 최종 UI 장식 → SB11 Damage Number → SB12 한국어 TMP → 공용 완성 표식·융합 VFX
3. 태환: 포함된 P1에 QA12·QA13, 포함된 엘리트에 QA14
4. 선동: 추가 밸런스와 VFX 매핑
5. 공통 P2: 소환 엘리트 → 마법별 고유 VFX → SFX → 셰이더·화면 연출 → Enemy HP Bar

VFX·SFX·TMP 에셋이 9월 8일 정오까지 저장소 또는 명시된 패키지 경로로 제공되지 않으면 완성 VFX·SFX·TMP 카드는 자동 보류한다. 담당자가 임시 에셋을 새로 만들어 대체하지 않는다. 기존 도형·색을 쓰는 P0 최소 표시는 유지한다.

## 브랜치와 소유권

- 유신은 `Combat/**`, 적·투사체 프리팹과 데이터, 새 Combat-side 마법 실행기만 수정한다.
- 승범은 `UI/**`, UI 프리팹·작업 씬, VFX·SFX 연결만 수정하고 공개 전투 이벤트를 구독한다.
- 선동은 Progression 규칙·카탈로그·Editor 통합 도구·Docs·`SampleScene` 최종 연결만 수정한다.
- 태환은 제품 소스를 수정하지 않고 통합된 `Seondong` SHA만 검증한다.
- 선동은 SD02에서 공용 공격 payload 계약을 먼저 확정한다. YS07에서 유신이 Combat 쪽 `ProjectileSpec`·적중부를 하위 호환으로 확장하면, 같은 날 SD05에서 선동이 Progression `MagicRuntime` 전달부를 연결·검증한다.
- 범위·융합 실행기는 유신이 Combat 쪽에서 `PlayerSkillSystem` 공개 이벤트를 구독한다. 유신이 Progression 코드를 고쳐 연결하지 않는다.
- 충돌은 파일 소유자 결과를 보존한다. 다른 담당자가 같은 기능을 다시 만들지 않는다.
