# 마법사 뱀서류 — 10분 한 판 기획·구현 계약

팀원이 처음 읽을 요약은 [GameDesignBrief.md](GameDesignBrief.md), 날짜별 담당 작업은 [TeamSchedule.md](TeamSchedule.md)를 따른다. 이 문서는 상세 규칙과 공개 계약의 원본이다. 이번 제출에 넣는 범위는 GameDesignBrief 「콘텐츠 목표와 제출 약속」의 P0 표가 기준이며, 이 문서의 P1·삭제 표기는 그 표를 따른다.

## 목표

- 수업 평가용 Unity Play Mode 빌드
- 직접 이동, 자동 공격, 적 처치 즉시 EXP
- 8분 성장 + 2분 보스전
- 차별점: 오각형 원소 트리, 원소별 3중첩 표식, 3+3 융합 반응
- 원소: 화염, 번개, 냉기, 대지, 암흑
- 콘텐츠 기준: 기본 마법 10개, 융합 마법 5개

스토리, 미술 방향, 구체적인 에셋·VFX 매핑은 이 문서 범위가 아니다.

현재 저장된 버전은 선동 담당 규칙·데이터·공개 계약 통합본이다. 실제 표식·플라즈마 전투, Tank·보스, 스킨 적용 흐름 UI는 [TeamRequests_10MinuteBuild.md](TeamRequests_10MinuteBuild.md)의 담당 결과를 병합한 뒤 완성된다.

## 한 판 흐름

1. 승범 타이틀에서 시작한다.
2. 시작 원소 하나를 무료로 선택한다.
3. 0~8분 동안 생존하고 성장한다.
4. 8분에 일반 스폰을 중단하고 남은 적을 EXP 없이 정리한다.
5. 원소 수호자 보스를 등장시킨다.
6. 10분 전에 보스를 처치하면 승리한다.
7. 플레이어 사망 또는 10분까지 보스 생존 시 패배한다.
8. 결과에 전투 시간, 킬, 레벨, 원소, 융합을 남긴다.

`ElementSelect`, `LevelUp`, `Victory`, `GameOver` 동안 시간은 멈춘다. `Playing`, `Boss` 동안만 전투 시간이 흐른다.

## 성장 규칙

- 시작 레벨 1
- 필요 EXP: `현재 레벨 × 5`
- 적 처치 시 EXP 즉시 획득
- 초과 EXP 보존
- 여러 레벨을 한 번에 얻으면 선택을 한 노드씩 처리
- 레벨업마다 최대 HP의 10% 회복
- 선택 저장, 건너뛰기, 초기화 없음
- 8분 목표 레벨 12~13

## 오각형 스킬트리

원소 순서:

`화염 → 번개 → 냉기 → 대지 → 암흑 → 화염`

- 시작 원소의 조준 마법은 무료
- 이후 보유 원소와 인접한 원소 루트만 획득 가능
- 각 원소: `조준 마법 → 범위 마법 → 원소 숙련`
- 두 원소 루트를 얻으면 사이 융합 가지가 보임
- 양쪽 원소 숙련 뒤 `융합 마법 → 융합 숙련`
- 원소 15 + 융합 10 + 공용 3 = 총 28노드 정의
- 이번 제출 공개 노드 20 = 원소 15 + 플라즈마 2 + 공용 3. 폭풍·동토·묘지·지옥불 8노드는 양쪽 원소를 보유해도 Hidden 고정
- 레벨업 때 노드를 선택하고 확인해야 적용

공용 노드는 각각 한 번만 선택한다.

- 위력 강화: 모든 마법·상태·반응 피해 ×1.15
- 속사 강화: 모든 자동공격 쿨다운 ×0.9
- 관통 강화: 투사체 관통 +1 (연쇄 없음)

일반 경로는 레벨 7에 플라즈마 융합이 가능하다. 8분 레벨 12~13이면 선택 12회, 공개 노드 20이라 소진되지 않는다. 두 번째 융합은 P1 융합 포함 시에만 있다.

## 마법 실행 규칙

- 조준 마법 5: 기존 투사체 흐름. `ProjectileSpec` 하위 호환 확장 payload로 적용 표식 목록(원소, 중첩)을 전달한다. 연쇄 없음. 필드 정의는 SD02' (9/4)
- 범위 마법 5: 플레이어 중심 원형 즉시 피해. 공용 실행기 1개 `AreaMagicRuntime`(선동, Progression). 피해·쿨다운·반경만 다르다. 불꽃 고리 반경은 SD02'
- 융합 공격(플라즈마 창): 조준 투사체와 같은 흐름. 관통 3, 화염·번개 표식 각 1 부여

## 표식·숙련·융합 공통 규칙

- 원소 공격 적중 시 같은 원소 표식 +1
- 원소별 독립 보관, 최대 3중첩, 지속시간 5초
- 같은 원소 재적용 시 지속시간 갱신
- 풀 반환 시 표식 전부 초기화
- 표시는 1~3단계 도형·색. 3중첩 맥동 VFX는 P1
- 표식 기본 효과는 원소 공통 1종: 중첩당 받는 피해 +5%. 모든 원소 중첩을 합산한다. 상한은 SD07에서 정하며 그 전엔 상한 없음
- 원소별 고유 효과 5종(화염 초당 피해, 번개 피해 증가, 냉기 둔화, 대지 밀치기, 암흑 피해 증가)은 P1
- 원소 숙련 노드는 해당 원소 마법 피해·범위 ×1.2만 적용
- 숙련 발동 5종(`2 → 3중첩` 1회 발동, 표식 소비·만료 뒤 재발동)은 P1
- 제어 효과(빙결·기절·둔화)는 이번 제출에 없음

융합은 플라즈마 1종만 활성한다. 폭풍·동토·묘지·지옥불은 카탈로그 정의만 유지하고 P1이다.

- 플라즈마 창: 관통 3 투사체, 화염·번개 표식 각 1 부여
- 화염·번개 표식이 3+3이면 즉시 반응: 피해 24, 반경 1.8, 8 피해 연쇄 3명
- 판정 시 부모 표식 6개 소비
- 반응 피해는 표식을 부여하지 않음
- 반응마다 `ElementCombatEvents.FusionReactionOccurred` 발행
- 플라즈마 숙련: 융합 공격·반응 피해 ×1.2, 반경 2.4, 연쇄 대상 5명
- 동시에 완성된 융합의 선판정·후소비 규칙은 P1 융합 포함 시에만 적용

정확한 10개 기본 마법, 5개 융합 공격·반응·숙련 수치는 `MagicContentCatalog`를 단일 원본으로 사용한다.

0~8분 진행률 `p`:

- 스폰 간격: 1.4초 → 0.35초
- 동시 적 상한: 25 → 100
- HP 배율: 1.0 → 1.6, `Enemy.ApplyDifficulty`로 실제 적용

- 이동속도 시간 배율 없음
- 새 적은 등장 뒤 45초 동안 목표 비중까지 증가
- 8분 비중 원안: 기본 35%, 빠름 30%, 탱커 20%, 원거리 15%. 비어 있는 슬롯은 `SpawnDirector`가 제외하고 존재하는 슬롯끼리 재정규화한다. Ranged 미포함 시 약 41%·35%·24%

보스:

- 8분 등장, HP 2,000, 1단계만
- 접촉 피해 + 패턴 1개: 조준 투사체 부채꼴 3발, 주기 N초. 주기·투사체 속도·피해·부채꼴 각은 SD03' (9/7)

- 처치 시 `RunDirector.ReportBossDefeated()` 호출 → 즉시 승리. 10분 생존 시 시간 초과 패배

## 공개 계약

게임 흐름:

```text
ElementSelect
Playing
LevelUp
Boss
Victory
GameOver
```

트리 상태:

```text
Hidden
Locked
Available
Owned
```

선동 런타임 공개 계약:

- `PlayerSkillSystem.GetTreeDefinitions()`
- `PlayerSkillSystem.GetNodeState()` / `GetNodePreview()`. 폭풍·동토·묘지·지옥불 8노드는 항상 Hidden
- `TryChooseStartingElement()`
- `TrySelectNode()` / `CancelSelectedNode()` / `ConfirmSelectedNode()`
- 노드·마법·원소·융합 이벤트
- 보유 마법·원소·융합 읽기 전용 목록
- `RunDirector` 시간·킬·보스 요청·결과 이벤트, `ReportBossDefeated()`. 엘리트 요청 이벤트는 남되 미사용
- `RunResult` 승패·시간·킬·레벨·원소·융합 스냅샷
- `IElementMarkTarget` 표식 계약. 제어 멤버 `CrowdControlDurationMultiplier`·`IsKnockbackImmune`는 이번 제출 미사용
- `ElementCombatEvents` 융합 반응 이벤트
- `SpawnDirector.EnemySpawned` 난이도 스냅샷 전달
- `AreaMagicRuntime` 범위 마법 공용 실행기 (선동, Combat 공개 API만 사용)

유신 Combat 공개 계약:

- `Enemy.ApplyDifficulty(healthMultiplier, damageMultiplier)` (`dbdbd2f`, 병합 완료). `SpawnDirector.EnemySpawned` 배선은 선동 SD05
- `Enemy : IElementMarkTarget` (`ba459d9`, `ElementMarkState` 위임)
- 조준 투사체 payload: `ProjectileSpec` 하위 호환 확장, 적용 표식 목록(원소, 중첩). 필드 정의는 SD02' (9/4) 뒤 이 자리에 기록
- `GameEvents.EnemyDamaged`: P1 Damage Number용. 유신이 피격부에서 발행, 승범이 구독

## 담당 경계

- 선동: 규칙, 데이터, 트리, EXP, 레벨업, 스폰 일정, 난이도 값, 보스 등장 조건, 승패, 결과, 범위 마법 공용 실행기 `AreaMagicRuntime`, `GrayboxGameFlowView` 로직·이벤트 연결
- 유신: 표식 저장·공통 효과, 조준 payload 적중부, 플라즈마 공격·3+3·반응 발행, Tank·보스 행동, `Enemy.ApplyDifficulty`, 모든 적 상태의 풀 초기화. P1: Ranged, 원소별 고유 효과, 숙련 발동, 나머지 융합, SPUM
- 승범: 기존 HUD·타이틀 유지, `GrayboxGameFlowView` 표현 레이어(스타일 필드·레이아웃 생성 구역·라벨·폰트·프리팹) 스킨, 표식·반응 최소 표시. P1: Damage Number, 한국어 TMP, VFX·SFX
- 태환: 기능·회귀·밸런스·100마리 성능·최종 검수

9월 3일 변경: (a) 범위 마법 실행기 유신 → 선동. (b) `GrayboxGameFlowView` 표현 레이어 → 승범, 로직·이벤트 연결은 선동 유지.

다른 담당자의 영역은 선동이 대체 구현하지 않는다. 공개 계약과 요청 이벤트까지 연결하고 담당 결과를 병합한다.

- 장비·상점·메타 성장
- 추가 캐릭터·맵
