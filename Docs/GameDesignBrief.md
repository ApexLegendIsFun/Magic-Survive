# Magic Survive — 팀 공용 기획 요약

## 문서 목적

이 문서는 모든 작업자가 먼저 읽는 한 장짜리 방향 기준이다. 정확한 수치와 구현 계약은 [TenMinuteRunPlan.md](TenMinuteRunPlan.md)와 코드의 `MagicContentCatalog`, `DifficultyRules`, `RunTimelineRules`를 따른다.

## 한 줄

플레이어가 마법사를 직접 이동시키고 자동 마법으로 몬스터 떼를 처치해, 다섯 원소 트리를 성장시키고 표식 3중첩과 플라즈마 3+3 반응으로 10분 안에 보스를 잡는 게임이다.

## 플레이 경험

- 조작: 이동만 직접, 공격은 자동
- 한 판: 8분 성장 + 2분 보스전
- 반복: 처치 → 즉시 EXP → 레벨업 → 노드 선택·확정 → 새 마법과 조합 강화
- 차별점: 다섯 원소의 독립 표식 3중첩, 화염+번개 플라즈마 3+3 융합 반응. 원소별 고유 표식 효과·숙련 발동과 나머지 융합 4종은 P1
- 평가 대상: 수업 시연용 Unity Play Mode 한 판

## 한 판 흐름

```text
타이틀
  → 시작 원소 1개 선택
  → 0:00~8:00 생존·성장
  → 8:00 일반 스폰 중단·보스 등장
  → 보스 처치 시 승리 / 플레이어 사망 또는 10:00 도달 시 패배
  → 결과 확인
  → 재시작 또는 타이틀
```

원소 선택, 레벨업 선택, 승리, 패배 화면에서는 전투 시간이 멈춘다.

## 핵심 규칙

- 원소 순서: 화염 → 번개 → 냉기 → 대지 → 암흑 → 화염
- 트리: 원소 15 + 융합 10 + 공용 3 = 28노드 정의. 이번 제출 공개 노드는 20 (원소 15 + 플라즈마 2 + 공용 3). 폭풍·동토·묘지·지옥불 8노드는 Hidden 고정
- 시작 원소의 조준 마법은 무료다.
- 필요 EXP는 `현재 레벨 × 5`, 초과 EXP는 보존한다.
- 레벨업마다 최대 HP의 10%를 회복한다.
- 표식은 원소별 독립 저장, 최대 3중첩, 5초 유지, 같은 원소 재적중 시 시간을 갱신한다.
- 표식 기본 효과는 원소 공통 1종: 중첩당 받는 피해 +5%, 모든 원소 중첩 합산. 상한은 SD07 밸런스에서 정한다.
- 원소 숙련 노드는 해당 원소 마법 피해·범위 ×1.2만 적용한다. 원소별 고유 표식 효과 5종과 `2 → 3중첩` 숙련 발동 5종은 P1.
- 범위 마법 5종은 플레이어 중심 원형 즉시 피해다. 피해·쿨다운·반경만 다르다.
- 융합은 플라즈마 1종만 활성: 융합 공격이 화염·번개 표식을 각 1 부여하고, 3+3이면 둘 다 소비해 반응한다. 나머지 융합 4종은 정의만 두고 P1.
- 연쇄 없음. 공용 관통 강화는 관통 +1만. 제어 효과(빙결·기절·둔화)는 이번 제출에 없다.
- 정확한 기본 마법 10개, 융합 5개, 반응 수치는 `MagicContentCatalog`가 단일 원본이다.

## 완료 모습

- 시작 원소 5개 중 어떤 것을 골라도 조준·범위 마법으로 공격과 성장이 시작된다.
- 공개 노드 20개를 인접성과 선행 조건에 맞게 선택·확정할 수 있다. 폭풍·동토·묘지·지옥불 8노드는 정의만 남고 Hidden 고정이다.
- 적중한 적에 원소별 표식이 독립으로 쌓이고 5초 뒤 만료되며, 중첩당 받는 피해 +5%가 합산 적용되고, 풀 재사용 때 이전 상태가 남지 않는다.
- 외부 에셋 없이 기존 UI 도형·색으로 표식 1~3단계와 플라즈마 반응 여부를 볼 수 있다.
- 화염 시작 후 번개 가지를 여는 QA 경로에서 플라즈마가 융합 공격 → 3+3 소비 → 반응(피해 24, 반경 1.8, 8 피해 연쇄 3명) → `ElementCombatEvents`까지 끝에서 끝으로 작동한다. 다른 시작 원소는 조준·범위 마법과 성장 경로까지 필수 검증한다.
- 3:00부터 Tank가 섞이고 난이도 HP·피해 배율이 실제 적에 적용된다.
- 8:00에 보스(HP 2000, 접촉 피해 + 조준 투사체 부채꼴 3발 패턴 1개)가 등장하고, `RunDirector.ReportBossDefeated()` 호출로 승리, 10:00 시간 초과·사망으로 패배, 결과와 재시작·타이틀이 이어진다.
- `GrayboxGameFlowView` 흐름 UI에 승범 스킨(색·배치·폰트·라벨)이 적용된다. 스킨이 늦어도 기능은 그대로 남는다.
- Unity `6000.3.17f1`에서 컴파일 오류, Missing Script, 런타임 Error·Exception이 0이다.
- 1080p에서 적 100마리와 표식·보스 상태가 존재할 때 목표 60FPS를 확인한다.
- 최종 목표는 신규 플레이어 5명이 각 1회 플레이했을 때 보스 도달 4명, 승리 3명이다.
