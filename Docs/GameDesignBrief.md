# Magic Survive — 팀 공용 기획 요약

## 문서 목적

이 문서는 모든 작업자가 먼저 읽는 한 장짜리 방향 기준이다. 정확한 수치와 구현 계약은 [TenMinuteRunPlan.md](TenMinuteRunPlan.md)와 코드의 `MagicContentCatalog`, `DifficultyRules`, `RunTimelineRules`를 따른다.

## 한 줄

플레이어가 마법사를 직접 이동시키고 자동 마법으로 몬스터 떼를 처치해, 오각형 원소 트리를 성장시키고 3+3 융합 반응으로 10분 안에 보스를 잡는 게임이다.

## 플레이 경험

- 조작: 이동만 직접, 공격은 자동
- 한 판: 8분 성장 + 2분 보스전
- 반복: 처치 → 즉시 EXP → 레벨업 → 노드 선택·확정 → 새 마법과 조합 강화
- 차별점: 다섯 원소의 독립 표식 3중첩, 원소 숙련, 인접 원소 3+3 융합 반응
- 평가 대상: 수업 시연용 Unity Play Mode 한 판

## 한 판 흐름

```text
타이틀
  → 시작 원소 1개 선택
  → 0:00~8:00 생존·성장
  → 8:00 일반 스폰 중단·보스 등장
  → 보스 처치 시 승리 / 플레이어 사망 또는 10:00 도달 시 패배
  → 결과 확인
  → 재시작 또는 타이틀
```

원소 선택, 레벨업 선택, 승리, 패배 화면에서는 전투 시간이 멈춘다.

## 핵심 규칙

- 원소 순서: 화염 → 번개 → 냉기 → 대지 → 암흑 → 화염
- 트리: 원소 15 + 융합 10 + 공용 3 = 28노드
- 시작 원소의 조준 마법은 무료다.
- 필요 EXP는 `현재 레벨 × 5`, 초과 EXP는 보존한다.
- 레벨업마다 최대 HP의 10%를 회복한다.
- 표식은 원소별 최대 3중첩, 5초 유지, 같은 원소 재적중 시 시간을 갱신한다.
- 원소 숙련은 `2 → 3중첩` 순간 한 번 발동하고, 표식이 사라진 뒤 다시 발동할 수 있다.
- 활성 융합의 부모 원소 표식이 3+3이면 둘 다 소비하고 반응한다.
- 정확한 기본 마법 10개, 융합 5개, 숙련과 반응 수치는 `MagicContentCatalog`가 단일 원본이다.

## 콘텐츠 목표와 제출 약속

30일 원안은 일반 적 4종, 엘리트 2종, 기본 마법 10개, 융합 5개, 보스 1종이다. 현재 남은 기간에는 아래 우선순위를 적용한다. P1·P2는 삭제 확정이 아니라 Gate를 통과해야 일정에 넣는 목표다.

| 등급 | 제출 범위 | 원칙 |
|---|---|---|
| P0 — 현재 승인 범위 | 10분 승패, 시작 원소별 조준 마법 5개, 28노드 규칙·데이터, 다섯 원소 표식, 실제 3+3 플라즈마 1종, 최소 표식·반응 표시, 보스, 기능 UI·결과·재시작, 적 100마리 안정성 | 9월 17일 기능 완료. 표현이 늦으면 기존 회색 검증 UI를 유지해도 기능은 남긴다. 공개한 노드는 반드시 실제 효과까지 동작해야 한다. Gate에서도 선동이 변경을 명시하기 전에는 임의로 줄이지 않는다. |
| P1 — Gate 통과 시 | 범위 마법 5개, 고유 원소 숙련 5종, 나머지 융합 4종과 융합 숙련, Tank·Ranged, 돌진 엘리트, 최종 UI 시각 장식, Damage Number, 한국어 TMP, 공용 완성 VFX | P0가 일정 안에 끝난 사람만 다음 항목을 가져간다. |

## 완료 모습

- 시작 원소 5개 중 어떤 것을 골라도 공격과 성장이 시작된다.
- 인접성과 선행 조건에 맞게 공개된 노드를 선택·확정할 수 있다. 28노드 정의는 유지하되 전투 효과가 없는 P1 가지는 RC에서 숨긴다.
- 적중한 적의 원소 표식이 쌓이고 만료되며, 풀 재사용 때 이전 상태가 남지 않는다.
- 외부 에셋이 없어도 기존 UI 도형·색으로 표식 1~3단계와 플라즈마 반응 여부를 볼 수 있다.
- 화염 시작 후 번개 가지를 여는 QA 경로에서 플라즈마가 실제 공격부터 3+3 소비·반응까지 끝에서 끝으로 작동한다. 다른 시작 원소는 P0에서 조준 마법과 성장 경로까지만 필수 검증한다.
- 8분에 보스가 등장하고 처치 보고, 승리·시간 초과·사망, 결과와 재시작이 이어진다.
- Unity `6000.3.17f1`에서 컴파일 오류, Missing Script, 런타임 Error·Exception이 0이다.
- 1080p에서 적 100마리와 표식 상태가 존재할 때 목표 60FPS를 확인한다.
- 최종 목표는 신규 플레이어 5명이 각 1회 플레이했을 때 보스 도달 4명, 승리 3명이다.
