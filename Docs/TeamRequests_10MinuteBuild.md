# 10분 빌드 — 팀 요청

지시는 구현 방법보다 필요한 결과와 연결 계약만 공유한다.

## 맹유신 — 전투 결과 요청

기존 `EnemyManager`, `Enemy`, `WeaponRunner`, 투사체 풀링을 유지한 채 다음 전투 결과가 필요하다.

- 다섯 원소 표식과 숙련 효과가 `MagicContentCatalog` 수치대로 작동
- 활성화된 다섯 융합의 3+3 반응이 동시에 판정 가능
- 원거리 일반 적, 돌진 엘리트, 소환 엘리트, 2단계 보스가 기존 풀링 흐름에서 작동
- 보스 제어 효과 25%와 밀치기 면역 적용
- 선동의 스폰 난이도 스냅샷을 HP·피해 배율에 반영
- 동시 100마리에서 새 상태까지 안전하게 초기화·재사용

연결 기준:

- 표식: `IElementMarkTarget`
- 반응: `FusionReactionRules`, `ElementCombatEvents`
- 콘텐츠 수치: `MagicContentCatalog`
- 등장 일정: `RunDirector`의 엘리트·보스 요청
- 일반 스폰: `SpawnDirector.EnemySpawned`

완료 기준은 시작 원소별 공격, 표식 3중첩, 숙련 1회 발동, 3+3 소비, 보스 패턴과 100마리 성능이 Play Mode에서 확인되는 것이다.

현재 통합본은 이벤트와 데이터 계약까지 준비되어 있다. 엘리트·보스 요청에는 아직 구독자가 없고, 일반 적은 Basic·Fast만 연결되어 있으며 최종 수치와 다르다. 실제 전투 연결이 완료되면 선동이 기준 씬에 병합한다.

## 한승범 — UI·연출 결과 요청

현재 HUD와 타이틀 작업을 유지한 채 회색 검증 화면을 교체할 최종 UI가 필요하다.

- 시작 원소 오각형
- 직접 선택형 28노드 오각형 트리
- 이름, 효과, 선행 조건, 현재값→적용값, 확인 버튼
- 융합 가지의 숨김·잠김·해금·보유 표현
- 승리·패배 결과와 재시작·타이틀
- 한국어 TMP 폰트
- 표식 단계, 3중첩 맥동, 융합 반응 VFX 연결

연결 기준:

- 상태: `GameFlowController.StateChanged`
- 트리: `PlayerSkillSystem` 조회·선택·확정 API와 이벤트
- 결과: `RunDirector.ResultReady`
- HUD: 기존 `GameplayHudBinder`

레이아웃과 표현 방식은 승범 판단에 맡긴다. 최종 UI 연결 뒤 `GrayboxGameFlowView`만 제거한다.

현재 타이틀·HUD는 승범 작업을 그대로 사용한다. 회색 트리와 결과 화면은 규칙 검증용 폴백이다.
