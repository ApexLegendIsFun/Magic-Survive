04 / 스킬트리

오늘 만든 실제 목업 기준.

승범 · 스킬트리 UI
1. 왼쪽에서 원소 선택

보유 원소나 해금 가능한 인접 원소를 고른다. 원소를 바꿔도 선택 횟수는 줄지 않는다.

2. 오른쪽에서 카드 확인

선택 원소의 기본 성장과 특화 카드 3개를 본다. 새 원소는 해금 카드 1개만 나온다.

3. 카드 클릭으로 확정

기본 성장과 고른 특화를 함께 얻는다. 원소 레벨 +1, 남은 선택 −1. 모두 쓰면 전투로 돌아간다.

목업 예시: ‘집중 화염’ 선택 → Lv.4 기본 효과인 쿨다운 −10% + 특화인 화염탄 피해 +10%.

스킬트리 기본 연결은 핵심. 목업의 특화 3종 실제 적용은 사이드.
