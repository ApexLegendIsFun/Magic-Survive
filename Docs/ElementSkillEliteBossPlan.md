# Magic Survive — 5원소 전투 스킬·엘리트·보스 기획서

## 1. 개편 목표

기존 28노드·융합 중심 구조를 줄인다.

- 화염·번개·냉기·대지·암흑 5원소만 사용한다.
- 원소마다 자동 전투 스킬 1개를 가진다.
- 스킬은 1~8레벨까지 성장한다.
- 3·5·8레벨에서 전투 방식이 크게 바뀐다.
- 이동은 직접 조작한다.
- 공격은 자동으로 발동한다.
- 10분 생존 구조는 유지한다.
- 엘리트 2종과 최종 보스 1종을 추가한다.

이번 개편에서는 융합 마법과 공용 강화 노드를 사용하지 않는다.

중요: 기존 28 스킬트리는 이번 개편에서 사용하지 않는다. 신규 게임에서는 5원소 오각형 스킬트리만 표시하고 적용한다. 기존 28노드 데이터와 코드는 당장 삭제하지 않고 호환·롤백용으로 남겨두되, 게임 진행과 UI에서 호출하지 않는다.

## 2. 한 판 흐름

| 시간 | 내용 |
|---:|---|
| 0:00 | 시작 원소 선택, 선택한 원소 1레벨 무료 획득 |
| 0:00~3:00 | 일반 몬스터 등장, 원소 스킬 성장 |
| 3:00 | 돌진자 등장 |
| 3:00~6:00 | 일반 몬스터 강화, 스킬 레벨업 |
| 6:00 | 소환술사 등장 |
| 6:00~8:00 | 최종 보스 준비 구간 |
| 8:00 | 일반 몬스터 중단, 원소 수호자 등장 |
| 8:00~10:00 | 보스 전투 |
| 10:00 | 보스 생존 시 패배 |

보스 등장 시 남아 있는 일반 몬스터와 엘리트는 제거한다. 제거된 적은 EXP를 주지 않는다.

## 3. 5원소 전투 스킬

### 공통 규칙

- 모든 스킬은 자동 공격이다.
- 원소 공격 적중 시 해당 원소 표식 1개를 적용한다.
- 표식은 원소별로 따로 저장한다.
- 표식 최대치는 3중첩이다.
- 표식 지속시간은 5초다.
- 같은 원소가 다시 적중하면 지속시간을 갱신한다.
- 스킬 레벨은 최대 8레벨이다.

### 공통 레벨 상승

| 레벨 | 효과 |
|---:|---|
| 1 | 기본 공격 해금 |
| 2 | 피해 +15% |
| 3 | 첫 번째 원소 고유 효과 해금 |
| 4 | 쿨다운 -10% |
| 5 | 공격 형태 확장 |
| 6 | 범위·관통·대상 수 강화 |
| 7 | 원소 고유 효과 강화 |
| 8 | 원소 각성 효과 해금 |

수치는 초기 밸런스 기준이다. QA 후 조정할 수 있다.

### 화염 — 지속 피해와 폭발

역할: 한 적을 오래 공격하고 주변으로 피해를 퍼뜨린다.

| 레벨 | 효과 |
|---:|---|
| 1 | 화염탄 1발. 피해 6, 쿨다운 0.8초. 화염 표식 1 적용 |
| 3 | 화염 표식 3중첩 시 점화. 피해 12, 반경 1.3 폭발 |
| 5 | 점화 또는 화염 적 사망 시 주변 적 최대 2명에게 화염 표식 1 전염 |
| 6 | 화염탄 관통 +1 |
| 7 | 점화 폭발 피해 +25%, 반경 +20% |
| 8 | 점화 폭발 후 2초 동안 불장판 생성. 0.5초마다 피해 4 |

2·4레벨은 공통 레벨 상승 효과를 적용한다.

### 번개 — 연쇄와 순간 폭딜

역할: 여러 적을 빠르게 연결하고 짧은 시간에 큰 피해를 준다.

| 레벨 | 효과 |
|---:|---|
| 1 | 번개탄 1발. 피해 5, 쿨다운 0.7초. 번개 표식 1 적용 |
| 3 | 번개 공격 3번째 적중마다 주변 적 최대 2명에게 60% 피해 연쇄 |
| 5 | 번개 표식 3중첩 시 방전. 반경 1.2, 피해 10 |
| 6 | 연쇄 대상 +1 |
| 7 | 방전 피해 +25% |
| 8 | 6초마다 표식이 있는 적 최대 3명에게 낙뢰. 대상당 피해 12 |

보스에게는 연쇄 대상이 보스 1명으로 제한된다. 낙뢰는 정상 적용한다.

### 냉기 — 둔화와 빙결

역할: 적의 움직임을 늦추고 위험한 적을 멈춘다.

| 레벨 | 효과 |
|---:|---|
| 1 | 얼음창 1발. 피해 5, 쿨다운 0.9초, 관통 1. 냉기 표식 1 적용 |
| 3 | 냉기 표식 3중첩 시 0.6초 빙결 |
| 5 | 빙결된 적이 피해를 받으면 파괴. 반경 1.2, 피해 8 |
| 6 | 얼음창 관통 +1, 냉기 표식 둔화 효과 +10% |
| 7 | 빙결 지속시간 +0.3초 |
| 8 | 빙결 해제 지점에 2.5초 서리 장판 생성. 장판 위 적 이동속도 -35% |

보스는 빙결되지 않는다. 보스에게는 둔화 효과도 적용하지 않는다.

### 대지 — 밀치기와 공간 제어

역할: 적을 밀어내고 주변 공간을 지킨다.

| 레벨 | 효과 |
|---:|---|
| 1 | 바위창 1발. 피해 8, 쿨다운 1.1초. 적을 짧게 밀친다 |
| 3 | 대지 공격 3번째 적중마다 충격파. 반경 1.5, 피해 10 |
| 5 | 충격파 지점에 2초 지진 구역 생성. 적 이동속도 -30% |
| 6 | 바위창 관통 +1, 충격파 반경 +15% |
| 7 | 밀치기 거리 +30% |
| 8 | 5번째 대지 공격마다 플레이어 주변에 낙석 3개 생성. 낙석당 피해 14 |

보스는 밀쳐지거나 기절하지 않는다. 대지 피해는 정상 적용한다.

### 암흑 — 저주와 처형

역할: 약한 적을 빠르게 정리하고 강한 적을 약화한다.

| 레벨 | 효과 |
|---:|---|
| 1 | 그림자 구체 1발. 피해 6, 쿨다운 1초, 관통 1. 암흑 표식 1 적용 |
| 3 | 암흑 표식 3중첩 적이 받는 모든 피해 +15% |
| 5 | 암흑 표식 3중첩 적 사망 시 주변 적 최대 3명에게 암흑 표식 1 전염 |
| 6 | 그림자 구체 관통 +1 |
| 7 | 암흑 피해 증가 효과 +10% |
| 8 | 체력 10% 이하 일반 적을 즉시 처형. 처형은 보스에게 적용하지 않는다 |

## 4. 5원소 스킬트리

### 구조

오각형 꼭짓점에 5원소를 배치한다.

```text
화염 ─ 번개
  │     │
암흑 ─ 대지
  \   /
   냉기
```

논리상 연결 순서는 다음과 같다.

`화염 → 번개 → 냉기 → 대지 → 암흑 → 화염`

### 획득 규칙

- 시작 원소 1개를 무료로 1레벨 획득한다.
- 새 원소는 보유 원소와 이웃한 원소만 선택할 수 있다.
- 보유 원소는 다음 레벨 카드를 선택할 수 있다.
- 한 번에 같은 원소의 레벨을 2 이상 올릴 수 없다.
- 레벨 8 스킬은 더 이상 레벨업 카드로 나오지 않는다.
- 융합 노드, 공용 강화 노드, 28노드는 플레이어 화면에서 제거한다.

### 레벨업과 스킬트리 통합 — 화면 목업 반영

- 별도 레벨업 화면과 스킬트리 화면을 두지 않고, 메뉴도 ‘성장’ 하나로 통합한다.
- 레벨업하면 ‘성장’ 화면을 열고, 같은 화면에서 오각형 원소 선택과 카드 확정을 진행한다.
- 평소에도 ‘성장’을 열어 확인할 수 있다. 화면 열람은 성장 횟수를 지급하지 않으며, 대기 레벨업이 없으면 카드 확정 버튼을 비활성화한다.
- 먼저 트리에서 강화할 원소를 고른다. 보유한 8레벨 미만 원소 또는 보유 원소에 인접한 새 원소만 선택 가능하다.
- 원소 선택·변경은 포인트를 소모하지 않는다. 선택한 원소의 카드만 오른쪽에 표시한다.
- 보유 원소는 특화 카드 3개 중 하나를 확정한다. 확정할 때 원소 레벨 +1, 대기 레벨업 횟수 -1을 한 번에 적용한다.
- 기존 1~8레벨 표의 효과는 기본 성장으로 유지한다. 선택한 특화는 기본 성장에 추가된다. 3·5·8레벨 고유 효과도 기본으로 얻는다.
- 새 원소는 기본 스킬 해금 카드 1개를 확정하여 1레벨을 얻는다. 이때 특화는 선택하지 않으며 레벨업 1회를 사용한다.
- 게임 시작의 무료 원소 1레벨은 별도이며 포인트를 소모하지 않는다.
- 다중 레벨업은 한 번씩 처리한다. 다음 선택에서는 원소를 다시 고른다. 전투 중 트리 열람은 정보 확인용이다.

아래 카드는 HTML 목업용 제안 수치다. 아직 실제 전투 밸런스 확정값은 아니다.

| 원소 | 특화 1 | 특화 2 | 특화 3 |
|---|---|---|---|
| 화염 | 화염탄 피해 +10% | 점화 반경 +10% | 불장판 지속시간 +10% |
| 번개 | 번개탄 피해 +10% | 연쇄 탐색 거리 +10% | 방전 피해 +10% |
| 냉기 | 얼음창 피해 +10% | 빙결 지속시간 +10% | 서리 장판 반경 +10% |
| 대지 | 바위창 피해 +10% | 충격파 반경 +10% | 밀치기 거리 +10% |
| 암흑 | 그림자 구체 피해 +10% | 전염 탐색 거리 +10% | 3중첩 피해 증가 효과 +2%p |

목업 가정: 원소별 고정 3종을 중복 없이 표시하며 다음 레벨업에서 같은 특화를 다시 선택할 수 있다. +10%는 해당 효과의 기본값 기준 가산, +2%p는 퍼센트포인트 가산이다. 미해금 효과의 특화는 저장했다가 해금 시 적용한다. 실제 기본 거리·반경이 없는 항목은 추가 정의가 필요하다. 카드 추첨·희귀도는 이번 목업에 넣지 않는다.

스킬 5개가 모두 8레벨이면 레벨업 창을 열지 않고 최대 HP의 10%를 회복한다.

### 기존 코드와의 연결

- `PlayerSkillSystem`은 원소별 런타임 스킬을 최대 5개 관리한다.
- `PlayerSkillTree`는 노드 소유 대신 원소별 레벨을 관리한다.
- `MagicRuntime`와 `WeaponRunner`의 자동 공격 흐름은 유지한다.
- `MagicContentCatalog`를 5원소 스킬 수치의 단일 원본으로 사용한다.
- `SkillLevelChanged(element, level)` 이벤트를 추가한다.
- `ProjectileSpec`에는 원소와 스킬 레벨 정보를 전달한다.
- 표식·빙결·밀치기·폭발·연쇄 처리는 Combat 영역에서 수행한다.
- 기존 28노드 관련 UI와 에디터 테스트는 5원소 레벨 기준으로 교체한다.

기존 코드의 담당 경계를 지킨다. Combat 담당자가 적 효과를 만들고, Progression 담당자가 성장 규칙을 만든다. UI 담당자는 공개 데이터만 읽는다.

## 5. 엘리트 몬스터

### 공통 규칙

- 엘리트는 종류마다 한 판에 한 번만 등장한다.
- 생성 시점의 난이도 배율을 적용한다.
- 엘리트 처치 시 지정 EXP를 즉시 지급한다.
- 보스 등장 시 엘리트는 제거하고 EXP를 주지 않는다.
- 엘리트 생성은 기존 `EliteSpawnRequested` 이벤트를 사용한다.

### 돌진자

등장 시간: 3:00

| 항목 | 값 |
|---|---:|
| 기본 HP | 180 |
| 접촉 피해 | 20 |
| 기본 이동속도 | 1.8 |
| 처치 EXP | 15 |
| 돌진 주기 | 8초 |
| 예고 시간 | 1.2초 |
| 돌진 시간 | 0.8초 |
| 돌진 속도 | 기본 이동속도의 4배 |

행동:

1. 플레이어를 향해 이동한다.
2. 돌진 전 붉은 방향선으로 공격 방향을 표시한다.
3. 예고가 끝나면 표시 방향으로 돌진한다.
4. 벽이나 화면 밖으로 나가면 플레이어 추적을 다시 시작한다.
5. 돌진 중에는 방향을 바꾸지 않는다.

### 소환술사

등장 시간: 6:00

| 항목 | 값 |
|---|---:|
| 기본 HP | 260 |
| 접촉 피해 | 12 |
| 기본 이동속도 | 1.0 |
| 처치 EXP | 25 |
| 소환 주기 | 8초 |
| 소환 예고 | 0.8초 |
| 1회 소환 수 | 빠른 적 3마리 |
| 원거리 공격 주기 | 2.5초 |
| 원거리 공격 피해 | 8 |

행동:

1. 플레이어와 일정 거리를 유지하려고 한다.
2. 8초마다 플레이어 주변에 소환 위치를 표시한다.
3. 예고 후 빠른 적 3마리를 소환한다.
4. 소환된 적은 EXP를 주지 않는다.
5. 소환 사이에는 느린 원거리탄을 발사한다.
6. 동시에 존재하는 소환 적은 최대 6마리다.

## 6. 최종 보스 — 원소 수호자

### 기본 정보

| 항목 | 값 |
|---|---:|
| 등장 시간 | 8:00 |
| 기본 HP | 2,000 |
| 접촉 피해 | 20 |
| 처치 EXP | 없음 |
| 페이즈 | 2개 |
| 패턴 | 3개 |

보스는 표식과 피해 증가 효과를 받는다.

보스는 다음 효과에 면역이다.

- 빙결
- 기절
- 밀치기
- 일반 적 처형

### 1페이즈 — 수호

범위: HP 100%~70%

- 플레이어를 천천히 추적한다.
- 4.5초마다 부채꼴 투사체 3발을 발사한다.
- 투사체 간격은 20도다.
- 투사체 피해는 10이다.
- 투사체 속도는 6이다.
- 접촉 시 피해 20을 준다.

### 2페이즈 — 폭주

범위: HP 70%~0%

- 이동속도 25% 증가.
- 부채꼴 투사체가 5발로 증가한다.
- 부채꼴 투사체 주기가 4초로 줄어든다.
- 5초마다 원형 충격파를 사용한다.
- 충격파는 0.8초 예고 후 발동한다.
- 충격파 반경은 2.5, 피해는 18이다.
- 10초마다 빠른 적 2마리를 소환한다.
- 보스 소환 적은 EXP를 주지 않는다.

### 보스 승패 처리

- `BossSpawnRequested` 수신 시 보스를 생성한다.
- 보스 사망 시 `RunDirector.ReportBossDefeated()`를 호출한다.
- 보스 처치 성공 시 즉시 승리 화면으로 이동한다.
- 10:00까지 보스가 살아 있으면 시간 초과 패배다.
- 보스 생성과 사망 뒤 상태는 풀 반환 시 모두 초기화한다.

## 7. 개발 순서

1. 28노드 관련 공개 UI와 선택 흐름을 5원소 레벨 흐름으로 변경한다.
2. 5원소 1~8레벨 데이터를 작성한다.
3. 원소별 레벨업 카드와 `SkillLevelChanged` 이벤트를 연결한다.
4. 투사체와 범위 공격에 원소·스킬 레벨 정보를 전달한다.
5. 화염·번개·냉기·대지·암흑 고유 효과를 연결한다.
6. 돌진자 데이터와 돌진 행동을 구현한다.
7. 소환술사 데이터와 소환·원거리 공격을 구현한다.
8. 원소 수호자 생성과 처치 승리 연결을 구현한다.
9. 보스 2페이즈와 3개 패턴을 구현한다.
10. UI에 원소별 레벨과 고유 효과를 표시한다.
11. 8분 전환, 10분 패배, 재시작을 검증한다.
12. 성능과 밸런스를 조정한다.

## 8. 테스트 기준

### 스킬

- 5개 시작 원소가 모두 정상 시작한다.
- 이웃 원소만 해금된다.
- 모든 원소가 1~8레벨까지 오른다.
- 레벨업 카드가 같은 레벨을 중복 제공하지 않는다.
- 레벨 8 스킬은 더 이상 카드에 나오지 않는다.
- 화염 폭발·번개 연쇄·냉기 빙결·대지 충격파·암흑 저주가 각각 발동한다.
- 표식은 3중첩과 5초 만료 규칙을 지킨다.
- 재시작 시 원소 레벨과 표식이 초기화된다.

### 엘리트

- 돌진자가 3:00에 한 번 생성된다.
- 돌진 예고가 보이고 예고 방향으로 돌진한다.
- 소환술사가 6:00에 한 번 생성된다.
- 소환 적 최대 6마리 제한이 지켜진다.
- 소환 적이 EXP를 지급하지 않는다.
- 엘리트 처치 EXP가 한 번만 지급된다.

### 보스

- 보스가 8:00에 한 번 생성된다.
- 일반 스폰이 중지된다.
- HP 70%에서 2페이즈로 전환된다.
- 부채꼴 투사체·충격파·소환 패턴이 정상 작동한다.
- 빙결·기절·밀치기·처형 면역이 작동한다.
- 보스 처치 시 승리한다.
- 10:00까지 보스 생존 시 패배한다.
- 보스 사망과 재시작 뒤 풀 상태가 깨끗하게 초기화된다.

### 성능

- 일반 적 100마리 상태에서 60FPS를 확인한다.
- 표식이 적용된 적 50마리 이상을 60초 유지한다.
- 엘리트 소환 적과 보스 투사체가 풀링된다.
- 런타임 Error와 Exception이 없어야 한다.

## 9. 밸런스 기준

- 8분 도달 레벨 목표: 12~16.
- 8분까지 원소 2~4개와 레벨 3~6 스킬을 볼 수 있어야 한다.
- 시작 원소에 따라 초반 생존 난이도가 크게 달라지면 안 된다.
- 화염은 보스 단일 피해가 강하다.
- 번개는 적이 많을 때 강하다.
- 냉기는 생존에 강하다.
- 대지는 포위 탈출에 강하다.
- 암흑은 약한 적 정리에 강하다.
- 어떤 원소 하나만 선택해도 보스에 도전할 수 있어야 한다.
- 수치는 QA 플레이 결과에 따라 조정한다.

## 11. 에셋 선택과 적용

### 방향

전체 스타일은 2D 픽셀 판타지로 통일한다.

- 캐릭터: SPUM 픽셀 캐릭터
- 적·보스: 픽셀 또는 카툰 픽셀 몬스터
- 스킬: 픽셀 애니메이션 VFX
- UI: Casual Fantasy GUI
- 글꼴: NanumGothic SDF
- 셰이더: All In 1 Sprite Shader는 필요한 대상만 사용

현재 에셋은 로컬의 `Assets/Untracked Asset`에서 확인했다. 이 폴더는 저장소에서 무시된다. 팀원이 같은 에셋을 써야 하므로 원본 패키지는 기존 팀 배포 방식으로 가져오고, 프로젝트에는 필요한 프리팹·참조만 연결한다.

현재 보유 에셋으로 이번 개편 범위를 모두 표현할 수 있다. 신규 에셋 구매는 보류한다. 팀원이 패키지를 받지 못한 경우에만 원본 패키지를 다시 배포한다.

### 적용 순서

1. 에셋 패키지를 팀 공용 방식으로 가져온다.
2. SPUM 플레이어와 일반 적 프리팹을 먼저 만든다.
3. `Enemy_Basic`, `Enemy_Fast`, Tank, Elite, Boss 데이터에 프리팹을 연결한다.
4. 원소별 대표 VFX 1개씩만 먼저 연결한다.
5. 스킬 3·5·8레벨의 폭발·상태 VFX를 추가한다.
6. 보스 예고와 2페이즈 VFX를 연결한다.
7. UI·폰트·데미지 숫자·사운드를 마지막에 연결한다.
8. 화면이 복잡하면 VFX 수명과 발동 빈도를 줄인다.

### 에셋 적용 기준

- 외부 에셋 원본은 수정하지 않는다.
- 원본 프리팹을 직접 고치지 않고 프로젝트용 Variant를 만든다.
- 프리팹마다 `Enemy`, `Health`, Collider를 확인한다.
- 보스는 애니메이션과 충돌 Collider를 분리한다.
- VFX는 풀링한다.
- 에셋 데모 씬은 빌드 씬에 넣지 않는다.
- `Assets/Untracked Asset` 전체를 저장소에 추가하지 않는다.
- 실제 사용 파일과 라이선스 문서만 팀 공용 패키지에서 관리한다.

## 12. 변경 범위

이번 개편에서 제거하는 것:

- 기존 28노드 표시
- 원소별 조준·범위·숙련 노드 분리
- 융합 마법과 융합 숙련
